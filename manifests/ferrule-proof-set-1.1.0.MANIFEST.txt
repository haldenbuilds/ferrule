ferrule-proof-set-1.1.0 - what is in the download

The exact file list, published before purchase. Every line is checkable against your own download.

All 106 files are listed below with a sha256 you can compute yourself.

Three things the two manifests INSIDE the download deliberately leave out. Each is a rule
rather than an oversight, and none of them applies to this list:

  1. harness/delivery.json carries a hash for every shipped file except itself. Nothing
     carries its own hash.
  2. FILE-MANIFEST.md leaves two files off its size table: itself, because writing its own
     size would change it, and delivery.json. So its headline count and its size sum each
     name the set they are true of rather than sharing one number that fits neither.
  3. harness/fence.denylist.json ships empty and the release asks you to fill
     it in, so delivery.json does not carry its hash either. Requiring a file you are told
     to edit to match the bytes that shipped would mean that following the instructions
     breaks the integrity check, and that check runs before everything else, so the
     correct install would be the unverifiable one.

THIS list hashes every entry in the archive, including all three of the above. It is the
record kept outside the download, so it has no reason to leave anything out, and the two
inside can be checked against it.
