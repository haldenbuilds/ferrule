The FERRULE Proof Set, Release 1.0: the complete file list

83 files. The 81 listed below total about 984 KiB. Node 18 or newer, zero
dependencies, no network access, no account.

This is every file in the release, by name and size. It is published so that what you are
getting is a list you can read rather than a description you have to trust. After you
download, harness/delivery.json carries the sha256 of each one and the harness checks
every file against it before it runs anything.

(Two files are not listed below. harness/delivery.json is not, because nothing carries
its own hash. This file is not, because it cannot state its own size without changing it.
Both ship, and delivery.json does carry this file's hash. That is also why the size above
is stated over the 81 on the list rather than over all 83: a file whose size cannot be
stated here is one this total has no honest way to include, and a count of one set printed
beside a sum of another is a number nobody can reconcile against the list.)

(One file below ships and is deliberately NOT hashed: harness/fence.denylist.json. It
arrives empty and the release asks you to fill it in, so requiring it to match the bytes
that shipped would mean following the instructions breaks the integrity check. The two
rules cannot both apply to one file, and the one that gives way is the hash.)

What you also get, which is not a file

Nothing. There is no onboarding call, no setup review, no support entitlement and no
update stream attached to this release. What is on this list is what there is, and that is
a deliberate shape rather than an omission: everything here is delivered by download, with
nobody on the other side, which is why the list can be complete.
